# Лабораторная работа №2 (Циклы) — Вариант 7

## Задание
Вычислить сумму S = 1/1! + 1/3! + 1/5! + 1/7! + ...
Вычисление прекратить, как только очередное слагаемое по модулю станет меньше ε.
Вывести сумму, последнее слагаемое, количество итераций.

## Формула
S = Σ 1/(2k-1)!,  k = 1, 2, 3, ...

## Тест-кейсы
| ε | Ожидаемая сумма | Итераций |
|---|-----------------|----------|
| 0.1 | ~1.1667 | 2 |
| 0.01 | ~1.175 | 3 |
| 0.000001 | ~1.175201 | 5 |
| 0.0000000001 | ~1.1752011936 | 6 |

## Проверка
Теоретическое значение: sinh(1) = 1.1752011936...

## Вывод
Сумма сходится к sinh(1). Факториал быстро растёт,
поэтому для ε = 10⁻⁶ достаточно ~5 итераций.
